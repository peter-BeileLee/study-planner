## 目录

- `index.html`：网站入口，继续直接打开此文件。
- `assets/js/app.js`：页面交互、日程组合、打卡与版本升级。
- `assets/js/cloud.js`：原云同步适配代码。
- `assets/css/app.css`：网站样式。
- `assets/images/`：静态图片与辅助图表。
- `data/schedule.js`：正式课表、日期课程、默认学习安排与任务数据。
- `化学/`、`数学/`：按学科归档的试卷资料；内部继续按年份、考试季和卷子类型组织。
- `tools/`：辅助绘图、试卷下载和资料检查脚本。请从项目根目录运行脚本，以保持相对路径指向正确。
